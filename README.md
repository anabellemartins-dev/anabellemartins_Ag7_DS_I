# anabellemartins_Ag7_DS_I
Classificador de consumo de água com alertas educativos — atividade de Desenvolvimento de Sistemas I (Estrutura de Decisão)

📌 Sobre o projeto
Programa em Python desenvolvido para uma campanha de conscientização ambiental de uma companhia de saneamento. O sistema classifica o perfil de consumo de água de um imóvel (comercial, casa ou apartamento) e emite um alerta educativo com base no consumo mensal informado, incentivando o uso consciente da água.

🐍 Linguagem
Python 3

⚙️ Como funciona
O programa solicita:

🏠 O tipo do imóvel (comercial, casa ou apartamento)

🚰 O consumo mensal de água, em metros cúbicos (m³)

E, com base nessas informações, exibe uma das mensagens:
Situação	Mensagem
Imóvel comercial	Tarifa comercial aplicada – consulte o plano corporativo.
Apartamento com consumo menor que 10 m³	Consumo econômico – excelente controle de água!
Casa ou apartamento com consumo de até 25 m³	Consumo moderado – dentro do padrão residencial.
Consumo acima do limite residencial	Consumo excessivo – adote medidas de economia e verifique vazamentos.

▶️ Como executar
Certifique-se de ter o Python 3 instalado e rode, no terminal:
python3 app.py
Em seguida, digite o tipo do imóvel e o consumo mensal quando solicitado.

🧪 Exemplo de execução
Digite o tipo do imóvel (comercial, casa ou apartamento): apartamento
Digite o consumo mensal de água (em m3): 8
Consumo econômico – excelente controle de água!
